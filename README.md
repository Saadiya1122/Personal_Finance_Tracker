# Personal Finance Tracker

A Python application developed for the M602B Computer Programming project to help users manage their monthly income and expenses.

## Features

- **Expense Management:** Add expenses by category, amount, currency and optional description.
- **Income Management:** Manage income sources such as Salary, Freelance, Teaching, Business, Benefits and Other.
- **Monthly Summary:** Calculate monthly income, total expenses and remaining balance.
- **Currency Conversion:** Convert expenses into the main currency using ExchangeRate-API.
- **Spending Visualisation:** Display a bar chart showing monthly spending by category.
- **File Handling:** Save expense records in CSV format and income settings in JSON format.
- **Expense Deletion:** Delete a selected expense or delete all expenses after confirmation.
- **Graphical User Interface:** Use a Tkinter interface with dropdown menus, input fields and buttons.

## Technologies Used

- Python
- Jupyter Notebook
- Tkinter
- Matplotlib
- CSV and JSON
- ExchangeRate-API

- Matplotlib
